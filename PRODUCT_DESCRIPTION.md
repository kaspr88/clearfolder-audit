# Product Description Draft — ClearFolder Audit

## Name

ClearFolder Audit

## Short tagline

A safe Windows folder audit tool that turns disk scan results into a clear manual cleanup plan.

## One-paragraph description

ClearFolder Audit is a portable, read-only Windows app that helps users understand a folder before cleaning it. It scans recursively and reports total size, largest subfolders, largest files, exact duplicates, empty folders, extension distribution, and file age. Unlike cleanup-heavy tools, it does not delete or modify files. Instead, it creates a Safe Cleanup Plan and exports clear HTML/CSV reports for manual review.

## Who it is for

- Windows users who want a safe audit before deleting files.
- Office workers who need a share-folder report.
- Freelancers who audit client folders and deliver evidence.
- Non-technical users who find treemaps confusing.

## Key benefits

- Portable EXE.
- Read-only by design.
- TOP subfolders with percent of total.
- Exact duplicate detection by SHA-256.
- Safe Cleanup Plan instead of risky one-click deletion.
- HTML report with simple visual charts.
- CSV export bundle.
- Filters for extensions, folder names, and minimum file size.
- Explorer open/select actions from results.

## Why install it if WinDirStat, TreeSize Free, and WizTree exist?

The honest answer: power users who want the fastest or richest disk analyzer should probably use WizTree, TreeSize, or WinDirStat. ClearFolder Audit is for a narrower use case: **safe, evidence-based folder review**.

Reasons to use ClearFolder Audit:

1. It is intentionally read-only and avoids cleanup buttons.
2. It produces a Safe Cleanup Plan, not just raw scan data.
3. It combines duplicate review, old-large-file review, empty folders, extension stats, and age stats in one simple report.
4. It exports a client-friendly HTML report and CSV bundle.
5. It is simpler for users who do not need treemap-heavy workflows.

If the product later needs stronger differentiation, the niche should become: **folder audit reports for freelancers, offices, and shared drives**, not general disk visualization.

## Competitor comparison

- **WinDirStat**: free/open-source, strong treemap, extension ledger, folder tree, duplicate detection, filters, file operations, and cleanup actions. ClearFolder Audit is less powerful but safer and report-first.
- **TreeSize Free**: polished and mature with many export/chart options and disk management features. ClearFolder Audit is simpler and focused on a manual cleanup checklist.
- **WizTree**: extremely fast, especially on NTFS via MFT scanning. ClearFolder Audit is not trying to win speed; it focuses on safe report generation.
