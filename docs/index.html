ClearFolder Audit 0.2.0 · Portable Windows app · Read-only by design

Clean up folders with evidence, not guesswork.

ClearFolder Audit scans a Windows folder and creates a safe cleanup report: largest subfolders, biggest files, exact duplicates, empty folders, file types, file age, HTML/CSV exports, and a manual Safe Cleanup Plan.

✓ Safe Cleanup Plan

✓ Evidence exports

Export a visual HTML report and CSV files for spreadsheet review.

Who it is for

Use ClearFolder Audit when a folder cleanup needs a report first: shared folders, client/project archives, office folders, old backups, or messy Downloads/Desktop folders where deletion should be reviewed before action.

What it finds

Largest folders/files

See the folders and files responsible for most of the space, including percent of total size.

Exact duplicates

Detect duplicate groups using SHA-256 hashes. Review manually before cleanup.

Empty and old items

Find empty folders and older large files that may deserve manual review.
